Model sandbox — re-price the board

Move a slider and the board re-ranks with the same arithmetic the program ran. Nothing here is hardcoded to a name.

What this is. A radar, not a prediction: it says what a protocol's token would be worth if its record stayed as it is. It does not predict whether or when a token is issued.

Honest labels. A protocol “records no token” when DefiLlama's record carries none — never “has no token”: a listed protocol may still hold one its record does not carry. Wrapped, staked and bridged products of a token that already trades are set aside: WBTC is Bitcoin on Ethereum, not a launch waiting to happen. The watchlist is a floor, never a ceiling: the board ranks every rankable pre-token protocol down to the snapshot's $5M line.
